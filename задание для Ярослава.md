
# Проект: **Конструктор карточек страницы**

Нужно написать скрипт, который **умеет полностью управлять карточками на странице через DOM**: создавать их, перемещать, изменять, анализировать страницу и выводить информацию о ней.

Вся логика должна быть реализована через **набор функций**, которые можно вызывать из консоли.

---

# 1. Исходная страница

```html
<header>
  <h1 id="title">My Cards Page</h1>
</header>

<main>
  <section id="cards">
    <div class="card" data-id="1">Learn JavaScript</div>
    <div class="card" data-id="2">Learn DOM</div>
    <div class="card" data-id="3">Practice Coding</div>
  </section>
</main>

<footer id="footer">
  Demo page
</footer>
```

Добавить базовые стили карточек.

---

# 2. Модуль информации о странице

Нужно реализовать функцию:

```
pageInfo()
```

Она должна выводить:

- текущий URL страницы
    
- браузер пользователя
    
- платформу
    
- количество карточек на странице
    
- текст первой карточки
    
- текст последней карточки
    

Использовать:

- `window`
    
- `navigator`
    
- `location`
    
- `querySelectorAll`
    
- навигацию по DOM
    

---

# 3. Работа с карточками

Нужно сделать **мини-API управления карточками**.

---

## Создание карточки

Функция:

```
createCard(text)
```

Должна:

1. создать новый `div`
    
2. добавить класс `card`
    
3. добавить текст
    
4. добавить `data-id`
    
5. вставить карточку в конец блока `#cards`
    

Использовать:

- `createElement`
    
- `textContent`
    
- `classList`
    
- `dataset`
    
- методы вставки элементов
    

---

## Создание карточки через HTML

Функция:

```
createCardHTML(text)
```

Добавляет карточку через:

```
insertAdjacentHTML
```

---

# 4. Управление карточками

Нужно сделать функции управления порядком карточек.

---

## Перемещение карточки

```
moveFirstCardToEnd()
```

Перемещает первую карточку в конец списка.

---

```
moveLastCardToStart()
```

Перемещает последнюю карточку в начало.

---

## Клонирование

```
cloneCard(index)
```

Клонирует карточку по индексу и добавляет её в конец списка.

Использовать:

```
cloneNode(true)
```

---

## Удаление

```
removeCard(index)
```

Удаляет карточку по индексу.

---

# 5. Редактирование карточек

---

## Изменение текста

```
changeCardText(index, text)
```

```
textContent
```

---

## Полная замена карточки

```
replaceCard(index, text)
```

Использовать:

```
outerHTML / innerHTML
```

```
paintCards(color)
```

---


Функция:

```
getCardStyles(index)
```

- цвет
    
- padding
    

Использовать:

```
getComputedStyle
```

# 8. Работа с атрибутами

Каждая карточка имеет `data-id`.

Нужно сделать функции:

```
getCardId(index)
```

возвращает `dataset.id`

---

```
setCardStatus(index, status)
```

добавляет атрибут

```
data-status="..."
```

---

```
removeCardStatus(index)
```

удаляет атрибут.

---

# 9. Поиск элементов

Реализовать функцию:

```
findCards(text)
```

Она должна:

1. найти все карточки
    
2. вернуть те, где текст содержит переданное слово.
    

Использовать:

```
querySelectorAll
```

---

# 10. Анализ DOM структуры

Реализовать функцию:

```
analyzeDOM()
```

Она должна вывести:

- родителя блока карточек
    
- количество дочерних элементов
    
- всех соседей первой карточки
    
- список всех `data-id`
    

Использовать:

- `children`
    
- `parentElement`
    
- `nextElementSibling`
    
- `previousElementSibling`
