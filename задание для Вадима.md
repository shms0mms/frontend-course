
# Практическое задание — Панель пользователей (User Management)

Создайте **интерфейс управления пользователями** с использованием компонентов **shadcn/ui**.

Это будет **небольшая админ-панель**, где можно:

- просматривать пользователей
    
- искать пользователей
    
- менять роль пользователя
    
- удалять пользователя
    

---

# Шаг 1. Установка компонентов

Установите необходимые компоненты shadcn:

```bash
на сайте shadcn есть более точная установка каждой компоненты
```

Компоненты, которые понадобятся:

- Card
    
- Input
    
- Avatar
    
- Button
    
- Select
    
- AlertDialog
    
- Separator
    

---

# Шаг 2. Создайте карточку панели

Весь интерфейс должен находиться внутри **Card**.

Пример структуры:

```tsx
<Card>
  <CardHeader>
    <CardTitle>User Management</CardTitle>
  </CardHeader>

  <CardContent>
    Interface here
  </CardContent>
</Card>
```

---

# Шаг 3. Поиск пользователя

Добавьте **Input** для поиска пользователей.

Пример:

```tsx
<Input placeholder="Search user..." />
```

Поиск может работать:

- по имени
    
- по email
    

---

# Шаг 4. Список пользователей

Отобразите пользователей в виде списка.

Каждый пользователь должен содержать:

- Avatar
    
- Name
    
- Email
    
- Role
    
- Action buttons
    

Пример структуры:

```tsx
<div className="flex items-center justify-between">
  <div className="flex items-center gap-3">
    <Avatar>
      <AvatarFallback>JD</AvatarFallback>
    </Avatar>

    <div>
      <p>John Doe</p>
      <p className="text-sm text-muted-foreground">
        john@email.com
      </p>
    </div>
  </div>

  Actions here
</div>
```

Разделяйте пользователей с помощью **Separator**.

---

# Шаг 5. Изменение роли пользователя

Добавьте **Select** для изменения роли пользователя.

Роли:

- Admin
    
- Editor
    
- Viewer
    

Пример:

```tsx
<Select>
  <SelectTrigger className="w-[120px]">
    <SelectValue placeholder="Role" />
  </SelectTrigger>

  <SelectContent>
    <SelectItem value="admin">Admin</SelectItem>
    <SelectItem value="editor">Editor</SelectItem>
    <SelectItem value="viewer">Viewer</SelectItem>
  </SelectContent>
</Select>
```

---

# Шаг 6. Кнопка удаления пользователя

Добавьте кнопку **Delete**.

При нажатии должно появляться **AlertDialog подтверждение**.

Пример:

```tsx
<AlertDialog>
  <AlertDialogTrigger asChild>
    <Button variant="destructive">
      Delete
    </Button>
  </AlertDialogTrigger>

  <AlertDialogContent>
    <AlertDialogHeader>
      <AlertDialogTitle>
        Delete user?
      </AlertDialogTitle>
    </AlertDialogHeader>

    <AlertDialogFooter>
      <AlertDialogCancel>Cancel</AlertDialogCancel>
      <AlertDialogAction>
        Delete
      </AlertDialogAction>
    </AlertDialogFooter>
  </AlertDialogContent>
</AlertDialog>
```

---

# Требования к интерфейсу

Страница должна содержать:

- карточку панели
    
- поиск пользователей
    
- список пользователей
    
- аватары
    
- выбор роли через Select
    
- подтверждение удаления через AlertDialog
