# 2. Что такое запросы

Когда наше React-приложение хочет получить данные из интернета, оно делает **запрос**.

Например:

- список пользователей
    
- список товаров
    
- список задач
    
- картинку котика
    
- информацию о покемоне
    

### Простыми словами:

Наш сайт “спрашивает” у другого сайта:

> “Дай мне данные”

А другой сайт отвечает:

> “Вот данные”

---

# 3. Что такое API

**API** — это специальный адрес, по которому можно получать или отправлять данные.

Например:

```txt
https://jsonplaceholder.typicode.com/users
```

Если перейти по этому адресу, мы увидим данные.

---

# 4. Что такое JSON

Чаще всего API присылает данные в формате **JSON**.

JSON — это текст, который очень похож на JavaScript-объекты.

Пример:

```json
{
  "id": 1,
  "name": "Alex",
  "email": "alex@mail.com"
}
```

Если объектов много, то это будет массив:

```json
[
  { "id": 1, "name": "Alex" },
  { "id": 2, "name": "Masha" }
]
```

---

# 5. Что такое Axios

**Axios** — это библиотека, которая помогает делать запросы.

С её помощью можно:

- получать данные (**GET**)
    
- отправлять данные (**POST**)
    
- изменять данные (**PUT / PATCH**)
    
- удалять данные (**DELETE**)
    

### Почему Axios удобен:

- код короче
    
- проще читать
    
- легко использовать в React
    

---

Сначала нужно установить библиотеку:

```bash
npm install axios
```

Потом импортировать в компонент:

```js
import axios from "axios";
```

# 7. Самый главный тип запроса — GET

**GET** — это запрос на получение данных.

Например:

- получить пользователей
    
- получить товары
    
- получить задачи
    

---

# 8. Первый пример: получаем список пользователей

Мы будем использовать бесплатное API:

```txt
https://jsonplaceholder.typicode.com/users
```

---

## Код:

```jsx
import { useEffect, useState } from "react";
import axios from "axios";

function App() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    axios
      .get("https://jsonplaceholder.typicode.com/users")
      .then((response) => {
        setUsers(response.data);
      })
   
  }, []);

  return (
    <div>
      <h1>Список пользователей</h1>

      {users.map((user) => (
        <div key={user.id}>
          <p>{user.name}</p>
          <p>{user.email}</p>
        </div>
      ))}
    </div>
  );
}

export default App;
```

---

# 9. Разбираем код по шагам

---

## 1) useState

```js
const [users, setUsers] = useState([]);
```

Здесь мы создаём состояние для хранения пользователей.

- `users` — текущий список
    
- `setUsers` — функция для изменения списка
    

---

## 2) useEffect

```js
useEffect(() => {
  ...
}, []);
```

`useEffect` нужен, чтобы выполнить код **после загрузки страницы**.

То есть:

> Когда компонент появился на экране — сделать запрос

---

## 3) axios.get()

```js
axios.get("https://jsonplaceholder.typicode.com/users")
```

Это GET-запрос.

Он говорит:

> “Получи пользователей по этому адресу”

---

## 4) .then()

```js
.then((response) => {
  setUsers(response.data);
})
```

Когда данные пришли, Axios передаёт их в `response`.

### Важно:

Нужные данные находятся в:

```js
response.data
```

Именно их мы записываем в `users`.

---

## 5) .catch()

```js
.catch((error) => {
  console.log("Ошибка:", error);
});
```

Если запрос не сработал, мы попадём сюда.

---

## 6) users.map()

```jsx
{users.map((user) => (
  <div key={user.id}>
    <p>{user.name}</p>
    <p>{user.email}</p>
  </div>
))}
```

`map()` перебирает массив и создаёт JSX для каждого пользователя.

---

# 10. Более удобный способ — async / await

Есть два способа писать запросы:

1. `.then()` / `.catch()`
    
2. `async / await`
    

Для React часто удобнее **async / await**, потому что код читается проще.

---

## Пример:

```jsx
import { useEffect, useState } from "react";
import axios from "axios";

function App() {
  const [users, setUsers] = useState([]);

  useEffect(() => {
    async function fetchUsers() {
      try {
        const response = await axios.get(
          "https://jsonplaceholder.typicode.com/users"
        );
        setUsers(response.data);
      } catch (error) {
        console.log("Ошибка:", error);
      }
    }
    
    

    fetchUsers();
  }, []);

  return (
    <div>
      <h1>Пользователи</h1>

      {users.map((user) => (
        <p key={user.id}>{user.name}</p>
      ))}
    </div>
  );
}

export default App;
```

# 11. Что такое loading

Когда данные ещё не пришли, нужно показать пользователю, что идёт загрузка.

Например:

- “Загрузка…”
    
- спиннер
    
- анимация
    

---

## Пример с loading:

```jsx
import { useEffect, useState } from "react";
import axios from "axios";

function App() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);

  useEffect(() => {
    async function fetchUsers() {
      try {
        const response = await axios.get(
          "https://jsonplaceholder.typicode.com/users"
        );
        setUsers(response.data);
        
      } catch (error) {
        console.log("Ошибка:", error);
      } finally {
        setLoading(false);
      }
    }

    fetchUsers();
  }, []);

  if (loading) {
    return <h2>Загрузка...</h2>;
  }

  return (
    <div>
      <h1>Пользователи</h1>

      {users.map((user) => (
        <p key={user.id}>{user.name}</p>
      ))}
    </div>
  );
}

export default App;
```

# 12. Что такое error

Иногда запрос может не сработать:

- нет интернета
    
- ошибка в адресе API
    
- сервер не отвечает
    

Тогда нужно показать ошибку.

---

## Пример с error:

```jsx
import { useEffect, useState } from "react";
import axios from "axios";

function App() {
  const [users, setUsers] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function fetchUsers() {
      try {
        const response = await axios.get(
          "https://jsonplaceholder.typicode.com/users"
        );
        setUsers(response.data);
      } catch (error) {
        setError("Не удалось загрузить пользователей");
      } finally {
        setLoading(false);
      }
    }

    fetchUsers();
  }, []);

  if (loading) return <h2>Загрузка...</h2>;
  if (error) return <h2>{error}</h2>;

  return (
    <div>
      <h1>Пользователи</h1>

      {users.map((user) => (
        <div key={user.id}>
          <p>{user.name}</p>
          <p>{user.email}</p>
        </div>
      ))}
    </div>
  );
}

export default App;
```

# 13. Важные правила при работе с Axios

---

## Правило 1. Данные находятся в response.data

Неправильно:

```js
setUsers(response);
```

Правильно:

```js
setUsers(response.data);
```

---

## Правило 2. Если у тебя массив — начальное значение должно быть []

Правильно:

```js
const [users, setUsers] = useState([]);
```

Если поставить `null`, то `map()` сломается.

---

## Правило 3. В map() нужен key

Правильно:

```jsx
{users.map((user) => (
  <p key={user.id}>{user.name}</p>
))}
```

---

## Правило 4. useEffect не делаем async напрямую

Неправильно:

```js
useEffect(async () => {
  ...
}, []);
```

Правильно:

```js
useEffect(() => {
  async function fetchData() {
    ...
  }

  fetchData();
}, []);
```

# 14. Практическое задание на уроке

## Задание: Получить список задач (todos)

Используем API:

```txt
https://jsonplaceholder.typicode.com/todos?_limit=10
```

---

## Что нужно сделать:

1. Создать состояние для задач
    
2. Создать состояние `loading`
    
3. Создать состояние `error`
    
4. Сделать GET-запрос через Axios
    
5. Показать 10 задач
    
6. Если задача выполнена (`completed: true`) — показать:
    
    - ✅ Выполнено
        
7. Если задача не выполнена (`completed: false`) — показать:
    
    - ❌ Не выполнено
        

---

## Готовый шаблон:

```jsx
import { useEffect, useState } from "react";
import axios from "axios";

function App() {
  const [todos, setTodos] = useState([]);
  const [loading, setLoading] = useState(true);
  const [error, setError] = useState("");

  useEffect(() => {
    async function fetchTodos() {
      try {
        const response = await axios.get(
          "https://jsonplaceholder.typicode.com/todos?_limit=10"
        );
        setTodos(response.data);
      } catch (error) {
        setError("Не удалось загрузить задачи");
      } finally {
        setLoading(false);
      }
    }

    fetchTodos();
  }, []);

  if (loading) return <h2>Загрузка...</h2>;
  if (error) return <h2>{error}</h2>;

  return (
    <div>
      <h1>Список задач</h1>

      {todos.map((todo) => (
        <div key={todo.id}>
          <p>{todo.title}</p>
          <p>{todo.completed ? "✅ Выполнено" : "❌ Не выполнено"}</p>
        </div>
      ))}
    </div>
  );
}

export default App;
```

# 18. Итог урока

Сегодня мы узнали:

- **Axios** — это библиотека для запросов
    
- **GET** — это получение данных
    
- данные в Axios лежат в **response.data**
    
- в React мы часто делаем запрос внутри **useEffect**
    
- данные сохраняем через **useState**
    
- массив выводим через **map()**
    
- пока ждём данные — показываем **loading**
    
- если ошибка — показываем **error**

# 19. Главное правило урока

### Формула почти любого GET-запроса в React:

1. Создай `state`
    
2. Создай `loading`
    
3. Создай `error`
    
4. В `useEffect` сделай `axios.get()`
    
5. Сохрани данные через `setState`
    
6. Выведи через `map()`
